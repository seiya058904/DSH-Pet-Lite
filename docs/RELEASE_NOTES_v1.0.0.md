# DSH Pet Lite 1.0.0 — Core and Ultra

**Choose Core** for the complete official basic set: 11 animations / 2,651 frames,
with bounded movement and turns. **Choose Ultra** for idle/click/drag only:
3 animations / 723 frames and the smallest package. Both retain 24 fps timelines.

Both Windows x64 ZIPs run without Python, DeepSeek Harness, an account or a network
connection. Unzip and launch the named EXE. No services, autostart or administrator
access. Settings and per-user installation directories are separate; normally run
one pet at a time. Executables are unsigned.

The official 348.97 MB base ZIP contains eleven clips, not all 106 supported by the
upstream program. The previous code-only report mislabeled that comparison.
Historical Full 106 and the extra animation packs are not current release products.

Core is about 123.4 MB compressed; Ultra about 53.6 MB. Package/source hashes,
independent candidate measurements and exact final binary acceptance are provided
in SHA256SUMS.txt, BENCHMARKS-v1.0.0.zip and RELEASE-VALIDATION.json. Runtime comparisons
with the official program are descriptive when its action schedule cannot be matched.
CPU%, GPU, watts and physical monitor Present are not claimed as validated.
